# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1, summarized:

- Be respectful and constructive in issues, PRs, and discussions.
- No harassment, personal attacks, or discriminatory language.
- Assume good faith; disagree on technical merits, not people.

## Reporting

Report unacceptable behavior by opening a private security advisory (see
[`SECURITY.md`](SECURITY.md) for the mechanism) or, if that's not appropriate
for the report, by contacting the maintainer directly through their GitHub
profile. Reports are handled confidentially.

## Enforcement

Maintainers may remove comments, commits, code, issues, and PRs that violate
this code of conduct, and may temporarily or permanently ban contributors for
behavior they deem inappropriate, threatening, or harmful.
